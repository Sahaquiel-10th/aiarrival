# AI第二大脑诊断问卷与结果规则

> 对应页面：`/diagnosis`
>
> 对应代码：`app/diagnosis/page.tsx`
> 本文档记录当前线上问卷的全部问题、选项、计分规则和结果文案，方便后续集中修改。

## 一、当前数据如何保存

诊断现在分为“5题快速诊断”和“17题深度诊断”。

- 快速诊断提交后立即写入网站的线索数据库，包含联系方式、5项答案、入口类型和来源页面。
- 用户继续完成深度诊断后，17题答案、诊断类型、成熟度和推荐服务会更新到同一条线索记录。
- 用户中途退出深度诊断，已经提交的快速诊断仍然保留。
- 页面提交前会明确取得“保存本次填写内容并联系”的同意。
- 结果页继续保留微信二维码，作为人工咨询入口。
- 正式域名将线索写入服务器私有目录的追加记录文件；Sites备用部署使用D1数据库。两种方式都不再只存在浏览器内存。

## 二、5题快速诊断

快速诊断负责让广告流量先获得初步方向并留下有效联系方式。

### 01｜你目前的身份是？（单选，必填）

选项与深度诊断第01题一致。

### 02｜你最希望AI先帮你解决什么？（单选，必填）

- 帮我整理知识
- 帮我写文章 / 内容
- 帮我制作课程
- 帮我分析客户问题
- 帮团队快速学习我的经验
- 帮企业沉淀知识

### 03｜你的经验和资料现在主要在哪里？（单选，必填）

选项与深度诊断第05题一致。

### 04｜你希望以后让团队或客户一起使用吗？（单选，必填）

- 暂时只服务个人
- 希望未来团队使用
- 目前已经有团队需求

### 05｜怎样联系你？

- 你的称呼（选填）
- 手机号或微信号（必填）

## 四、诊断类型计分规则

系统分别计算“企业需求分”和“个人专家分”，再确定主要诊断类型。

### 企业需求分

| 条件 | 加分 |
| --- | ---: |
| 身份为“企业创始人 / 管理者”或“企业核心管理人员” | +2 |
| 工作情况包含“需要管理团队、复制经验” | +2 |
| 资产包含销售话术、产品资料或企业制度流程中的任意一项 | +1 |
| 目标包含“帮团队快速学习我的经验”或“帮企业沉淀知识” | +2 |
| 采用方式为“我要解决企业团队使用问题” | +3 |
| 团队需求为“目前已经有团队需求” | +3 |
| 团队需求为“希望未来团队使用” | +1 |
| 希望帮助为“希望企业团队使用AI” | +4 |

### 个人专家分

| 条件 | 加分 |
| --- | ---: |
| 身份为咨询顾问、培训讲师、销售/客服或专业人士 | +2 |
| 工作情况包含“需要大量输出内容” | +2 |
| 工作情况包含“经常与客户沟通” | +1 |
| 资产包含专业经验、客户案例、课程内容或文章内容中的任意一项 | +2 |
| 目标包含写文章、制作课程、分析客户问题或生成方案中的任意一项 | +2 |
| 采用方式为“我希望建立一个完整的个人AI系统” | +2 |
| 希望帮助为“希望建立自己的AI助手” | +3 |

### 类型优先级

1. 企业需求分达到5分：判定为“团队知识整理型”。
2. 否则，个人专家分达到5分：判定为“个人AI助手准备型”。
3. 两项都未达到5分：判定为“知识整理起步型”。

企业类型优先于个人专家类型。例如两项都达到5分时，结果会进入企业类型。

## 五、三类基础诊断结果

### A｜知识整理起步型

- 标签：知识整理起步型
- 标题：你现在最需要的，是先把重要经验稳定地记录和保存下来
- 说明：现阶段不用急着学习复杂AI。先把记录方式、资料位置和分类方法确定下来，AI以后才有可靠的内容可以使用。
- 推荐服务：创始人AI第二大脑启动服务
- 价格：¥3,999 起
- 服务说明：适合把软硬件选型、购买注册、自动同步、知识库配置和15天轻陪跑一次完成。

### B｜个人AI助手准备型

- 标签：个人AI助手准备型
- 标题：你的专业经验已经很有价值，下一步是让AI学会使用这些内容
- 说明：你的工作中有较多内容输出、客户沟通或专业判断。把这些资料整理好后，AI可以更贴近你的表达方式，帮助写作、研究和分析。

根据第06题再分两种推荐：

1. 如果选择“比较困难，经常找不到”或“基本靠回忆”
   - 推荐服务：创始人AI第二大脑启动服务
   - 价格：¥3,999 起
   - 说明：你的资料目前还不容易调用，建议先完成软硬件配置、自动同步和15天启动。
2. 其他情况
   - 推荐服务：个人AI知识分身升级服务
   - 价格：¥9,999
   - 说明：适合在完整启动服务之上，进一步构建能创作、答疑和对外分享的个人AI知识分身。

### C｜团队知识整理型

- 标签：团队知识整理型
- 标题：你需要解决的已经不只是个人记录，而是团队怎样共享经验
- 说明：你有明确的团队使用需求。建议先统一公司资料、账号和查看范围，让员工能快速找到制度、产品和优秀案例，再逐步增加具体AI用途。
- 推荐服务：企业知识资产与智能体系统
- 价格：¥30,000 起
- 服务说明：适合建设企业知识资产、岗位使用范围，并验证首个业务智能体。

## 六、成熟度结果

成熟度按照下列顺序判断，命中更高等级后不再继续向下判断。

### L3｜准备让团队使用AI

满足任意一项：

- 第16题选择“目前已经有团队需求”；
- 第15题选择“我要解决企业团队使用问题”。

### L2｜准备建立个人AI助手

未进入L3，并满足任意一项：

- 第15题选择“我希望建立一个完整的个人AI系统”；
- 第17题选择“希望建立自己的AI助手”；
- 第14题选择“经常使用AI解决工作问题”。

### L1｜已经开始使用AI工具

未进入L2或L3，并满足任意一项：

- 第14题选择“会使用一些AI工具”；
- 第13题选择过ChatGPT、Claude、豆包或DeepSeek等AI工具。

### L0｜刚开始了解AI

没有命中以上条件时使用。

## 七、工具方向结果

按以下顺序匹配，越靠前优先级越高：

1. 企业类型，并且使用飞书、钉钉或企业微信：沿用你们已有的办公平台，再增加企业资料库。
2. 企业类型，但未使用上述办公平台：企业资料库 + 员工账号和查看范围设置。
3. 使用Notion：保留Notion，再接入适合你的AI工具。
4. 使用得到，或希望“推荐一个简单方案，我直接使用”：适合你的便携采集设备 + 低门槛知识库，从最顺手的方式开始。
5. 个人专家类型：多种内容采集 + 个人知识库 + 可分享知识分身。
6. 其他情况：适合你的采集设备 + 自动同步 + 个人知识库。

## 八、现状观察结果

结果页固定展示三条观察，每条根据答案二选一。

### 资料是否容易查找

- 第06题为“比较困难，经常找不到”或“基本靠回忆”：过去的资料查找比较困难，整理优先级较高。
- 其他答案：你已有一定资料基础，可以从现有内容开始。

### 记录习惯

- 第08题为“想记录但经常忘”或“基本没有记录”：目前记录习惯不稳定，需要更省事的记录方式。
- 其他答案：你已有记录习惯，适合进一步统一和整理。

### 团队需求

- 第16题为“暂时只服务个人”：当前先服务个人即可，不必一开始做得太复杂。
- 其他答案：未来有团队使用机会，建议从一开始保留升级空间。

## 九、修改时最容易遗漏的位置

修改结果时，应同时检查：

1. 问题标题和选项；
2. 每一步的必填校验；
3. 企业需求分和个人专家分；
4. 三类基础结果文案；
5. 个人专家类型中的第06题分支；
6. 成熟度、工具方向和三条现状观察；
7. 落地页服务名称、价格和交付内容是否与诊断结果一致；
8. 自动化页面测试中的价格与关键文案。
